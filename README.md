# KasirKu

Website kasir PHP + MySQL untuk Laragon dan DBeaver.

## Instalasi
1. Ekstrak folder `kasir` ke `C:\laragon\www\`.
2. Jalankan Laragon dan klik Start All.
3. Buka DBeaver.
4. Jalankan file `database/schema.sql` pada koneksi MySQL.
5. Buka `http://localhost/kasir/`.

## Database
Database: kasir_db
Tabel: kategori, produk, transaksi.

Data contoh dimasukkan menggunakan INSERT INTO.
